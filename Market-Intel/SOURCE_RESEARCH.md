# Карта источников и интеграций для Market Intel

**Дата проверки: 18 августа 2026.** Цель — находить организации с документированным признаком потребности в промышленной коммутационной аппаратуре, а не «собирать любые названия компаний».

## Вывод исследования

### 1. ЕИС — основная система записи

ЕИС — единственный обязательный горизонтальный источник для значимой части 44-ФЗ и 223-ФЗ. Федеральное казначейство формулирует назначение официального сайта как свободный и безвозмездный доступ к полной и достоверной информации о контрактной системе и закупках отдельных видов юрлиц ([источник](https://roskazna.gov.ru/gis/eis-zakupki-gov-ru)).

С 01.01.2025 прежний свободный FTP-механизм закрыт; для регулярного машиночитаемого получения нужен сервис отдачи ЕИС и зарегистрированный потребитель. Описанный публичный маршрут: `zakupki.gov.ru/pmd/auth/welcome` → ЕСИА → «Регистрация нового потребителя машиночитаемых данных» → токен. Для физлица описан `getDocsIP` и заголовок/элемент `individualPerson_token`; endpoint: `https://int44.zakupki.gov.ru/eis-integration/services/getDocsIP` ([разбор с endpoint и последовательностью](https://temofeev.ru/info/articles/soap-xml-i-python-poluchaem-dannye-s-zakupki-gov-ru/)).

**Продуктовое решение:** приложение уже безопасно импортирует конкретную публичную карточку по номеру извещения. Production-fetcher ежедневных инкрементальных архивов включается только после выдачи токена и загрузки актуального XSD из ЕИС. Это сознательно: нельзя подменять официальный SOAP фиктивным REST или обходить ограничения.

### 2. Площадки — не все являются источниками read API

| Площадка | Что подтверждено | Решение в продукте |
|---|---|---|
| B2B-Center | Web-service существует; в июле 2025 площадка сообщила, что методы, XML-примеры и тарифы доступны в ЛК ([новость](https://www.b2b-center.ru/news/?id=520)). | Коннектор ожидает официальный WSDL и права вашей организации. Не выдумываем метод поиска и не скрейпим ЛК. |
| Фабрикант | Официальный API предлагает DEMO и WSDL; описанные функции — создание черновика, публикация, получение предложений ([страница API](https://www.fabrikant.ru/integration-api/)). | Маркируется **publisher API**, не подключается как feed потенциальных покупателей, пока площадка не выдаст read/search scope. |
| ТЭК-Торг | Официальный SOAP-regламент приводит WSDL `https://zakupki.tektorg.ru/soap-integration/index/wsdl`, метод `getToken`, `createProcedure...` ([регламент](https://www.tektorg.ru/storage/files/76/SOAP.%20Регламент%20информационного%20взаимодействия%20v.29.pdf)). | Это односторонняя интеграция публикации с ЭТП, а не законный массовый reader. Открытые URL импортируются адресно. |
| РТС-тендер | Есть публичные поисковые страницы и связь с ЕИС, но в проверенных материалах нет публичной спецификации внешнего read/search API; в ЛК описана настройка интеграции с ЕИС ([страница](https://223.rts-tender.ru/customer/lk/)). | ЕИС — база; публичный URL РТС — вторичная проверка. |
| Сбербанк-АСТ | Регламент требует просмотра неконфиденциальных аукционов в открытой части и интеграцию с официальным сайтом ([регламент](https://www.sberbank-ast.ru/Docs/Reglament44FZ.pdf)). | Нет ложного API-коннектора. Потребуйте у площадки письменные условия data feed, если он нужен. |

### 3. Бесплатные законные каналы

* **ГИС Торги:** официальный раздел публикует машиночитаемые открытые наборы и прямо разрешает свободное, бессрочное, безвозмездное использование, включая коммерческое, с сохранением ссылки на источник ([условия](https://torgi.gov.ru/opendata/)). Это не поток закупок реле, но полезный проектный сигнал для ЖКХ, энергетики, имущества и концессий.
* **Публичные RSS/Atom заказчика:** наиболее прозрачный no-key путь. Приложение принимает только URL опубликованного RSS/Atom; нельзя выдавать поисковую HTML-страницу за RSS.
* **Google News RSS:** рабочий бесплатный discovery-коннектор. Он никогда не считается первоисточником и помечается в источнике.

### 4. Платные/партнёрские REST-пути

* **ГосПлан API** заявляет REST-доступ к закупкам/контрактам ЕИС, тестовый сервер без ключа и production-key после регистрации ([сайт](https://gosplan.info/)).
* **DaMIA API-Закупки** документирует методы КТРУ, мониторинга и `key`; на странице заявлен стартовый пакет 100 запросов ([документация](https://damia.ru/apizakupki)).

Это не официальные API ЕИС. Перед подключением необходимы: DPA/договор, тестовая выборка, лимиты, контракт на обновление, сохранение URL ЕИС в каждой записи.

## Нормальная воронка, которую реализует сервис

1. Собрать/импортировать **документ**, а не название компании.
2. Сохранить source URL, дату сбора, внешний ID и фрагмент текста.
3. Выделить семантический сигнал: категория, бренд, параметры, закупочная лексика.
4. Открыть первоисточник, подтвердить статус процедуры, срок и допустимость эквивалента.
5. Только затем обогатить **юрлицо** по ИНН/ОГРН и назначить менеджеру.
6. Коммерческое предложение готовить после инженерной матрицы соответствия: катушка, контакты, AC/DC и категория применения, монтаж, степень защиты, сертификаты, пожарная/взрывозащита при необходимости, ЗИП, гарантия.

## Что запрещено архитектурой

* обход CAPTCHA, авторизации, robots или rate limits;
* браузерный скрейпинг личных кабинетов;
* сохранение токенов в клиентском JavaScript или Git;
* выдача найденного бренда за подтверждённую покупку;
* дедупликация ЕИС и ЭТП «на глаз» без номера/URL;
* обработка персональных данных для лидогенерации.
