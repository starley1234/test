# Market Intel — реальный поиск спроса на коммутационную аппаратуру

Приложение находится рядом с исходным проектом намеренно: это отдельный сервис, отдельная база SQLite и отдельные настройки. В нём **нет** seeded/demo-лидов. В реестр попадает только ответ живого коннектора либо текст, который оператор вставил из первичного документа.

## Запуск

```bash
cd Market-Intel
python -m venv .venv
. .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8090
```

Откройте `http://localhost:8090`. Swagger/API: `/docs`.

## Как получить API-доступ

### ЕИС: официальный машиночитаемый доступ

1. Перейдите на `https://zakupki.gov.ru/pmd/auth/welcome`.
2. Авторизуйтесь через ЕСИА, выберите регистрацию нового потребителя машиночитаемых данных (физлицо/ИП или юрлицо), заполните цель и направьте заявку.
3. После одобрения получите токен. Для физлица применяется `getDocsIP`; для юрлица — соответствующий сервис ЕИС. Актуальные XSD/EIS-инструкции нужно брать в личном кабинете: состав методов и правила доступа меняются.
4. Запишите токен **только в серверное окружение**, например `.env` (файл уже исключён из Git):
   ```env
   EIS_INDIVIDUAL_TOKEN=ваш_токен
   ```
5. Не кладите токен в фронтенд, репозиторий или URL. Настройте расписание, лимиты и журналирование в соответствии с условиями ЕИС.

Сервис не имитирует этот токен и не обходит ограничения. Пока токена нет, можно легально импортировать публичную карточку по известному номеру в интерфейсе.

### B2B-Center

1. Зарегистрируйте организацию на `b2b-center.ru` и выберите тариф/права, в которых доступен web service.
2. В личном кабинете откройте обновлённую документацию веб-сервиса, WSDL, перечень методов и тарифных ограничений (B2B-Center сообщает, что документация и XML-примеры доступны в ЛК).
3. Создайте техническую учётную запись с минимальными правами. Поместите секреты в переменные среды:
   ```env
   B2B_CENTER_LOGIN=...
   B2B_CENTER_PASSWORD=...
   ```
4. До включения методов сверьте название операции с текущим WSDL, добавьте ограничение частоты и сохранение ссылки на оригинальную процедуру. Не используйте экранный скрейпинг закрытых разделов.

### Если нужен быстрый REST вместо собственной интеграции ЕИС

ГосПлан предлагает REST-доступ к 44-ФЗ/223-ФЗ и тестовый сервер без ключа; продуктивный ключ выдаётся после регистрации. Это коммерческий агрегатор, а не официальный API ЕИС — сохраняйте URL ЕИС как доказательство. У DaMIA есть пробный пакет (в опубликованной документации заявлены 100 запросов) и API закупок; проверяйте договор, тариф и актуальные лимиты перед запуском.

## Что искать

Стартовые запросы: `промежуточное реле`, `интерфейсное реле`, `реле контроля фаз`, `контактор`, `тепловое реле`, а также бренды `Finder`, `Omron`, `Phoenix Contact`, `Schneider Electric`, `Siemens`, `ABB`, `Eaton`, `WAGO`, `Weidmüller`. Для реального оффера обязательна проверка: допустимости эквивалента, напряжения катушки, токовой категории (AC-1/AC-3/DC), числа/типа контактов, монтажа, сертификатов и срока поставки.

## Безопасность и законность

Не обходите CAPTCHA, robots/условия площадок, аутентификацию или лимиты. Не отправляйте не проверенные результаты в CRM как подтверждённую закупку. Храните URL, время сбора и фрагмент первоисточника; данные о физических лицах здесь не обрабатываются.
