# Архитектура Fractal-HoloNet

## 1. Концепция
Fractal-HoloNet — это нейросетевая архитектура с линейной сложностью $\mathcal{O}(N)$ по длине контекста и константной памятью $\mathcal{O}(1)$ на шаг инференса.
Она объединяет:
- **Комплексно-фазовый голографический резонанс** ($\mathbb{C}^d$);
- **Фрактальные октавные частоты** (геометрическая прогрессия масштабов памяти);
- **Непрерывный энкодер сигналов** (прямой прием аудио, ЭКГ, датчиков без токенизации);
- **Дистилляцию знаний** от внешних Teacher LLM (OpenAI-совместимый API).

## 2. Модульная структура
- `src/holonet/`: исходный код библиотеки и моделей.
- `scripts/`: рабочие процессы обучения, дистилляции и экспорта.
- `tests/`: наборы автоматических тестов (pytest).
- `data/`: обучающие корпуса и эталонные датасеты.
- `assets/`: графики производительности и масштабирования.
- `checkpoints/`: веса моделей.
- `exports/`: ONNX модели для продакшена.
