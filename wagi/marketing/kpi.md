# WenAGI — KPI-дашборд запуска

## Северная звезда
**Количество сожжённых $WAGI в день** — единственная метрика, объединяющая
утилити (реальные запросы) и виральность (ритуал сжигания).

## Метрики по фазам

## Ретеншн-метрики (еженедельно)
- WAU плейграунда / mainnet-гейта
- Median prompts per active key (цель ≥ 5)
- Retention D7 ключа (цель ≥ 35%)
- NPS по опросу в Discord (цель ≥ 40)

## Анти-метрики (тревога)
- Соотношение промптов «тест: wen agi?» к полезным > 70% → квесты
  перекалибровать (нужна полезность, не спам).
- Скорость сжигания падает 2 недели подряд → включает «эпохальный» контент
  (новая эра = инфоповод).
- Дамп-кластеры после TGE → публичный отчёт + байбек из казны по правилам.
