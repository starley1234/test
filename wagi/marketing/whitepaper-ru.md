# WenAGI ($WAGI) — Белая книга
### Токен, который сжигает путь к AGI

**Версия:** 1.0 · **Статус:** mainnet-ready · **Сеть:** Base (EVM, OP-stack)

---

## 1. Проблема

Два самых больших явления десятилетия — **крипта** и **LLM** — живут раздельно:

- Инференс ИИ оплачивается банковскими картами через закрытые шлюзы. Для
  не-людей (агентов, ботов, автономных сервисов) это тупик: у машины нет карты.
- У мем-токенов нет утилити. У AI-токенов часто нет причины существовать как
  токену. Обе категории теряют половину потенциала.

## 2. Решение

**WenAGI — децентрализованный рынок LLM-инференса, где единицей расчёта
является $WAGI.**

1. Разработчик (или ИИ-агент) получает API-ключ и платит **$WAGI за каждый
   запрос** к OpenAI-совместимому шлюзу.
2. Комиссия каждого запроса делится смарт-контрактом **InferenceMarket**:
   - **80%** — GPU-провайдеру, обслужшему запрос;
   - **15%** — DAO-казне (гранты, аудит, ликвидность);
   - **5%** — **сжигается навсегда**.
3. Прогресс сети публикуется оракулом **AGIProgressOracle** — одним числом
   0–100% в ответ на старейший вопрос крипты: **«wen AGI?»**.

## 3. Почему это завирусится

| Механика | Эффект |
|---|---|
| **Живой прогресс-бар до AGI** | Один общий счётчик для всего интернета. Мем-маяк: «мы на 7.3%». |
| **Карточка прогресса** | Пользователь делится PNG-карточкой «мои промпты сожгли N $WAGI» (Spotify Wrapped × crypto). |
| **Стена промптов** | Публичная лента анонимных запросов сети — бесконечный источник контента и скриншотов. |
| **Burn как ритуал** | Каждый промпт необратимо уменьшает supply. Пользователи конкурируют за сожжённое. |
| **Утилити-квесты аирдропа** | Очки выдаются за реальные запросы, а не за клики. |
| **Имя и маскот** | «WEN AGI?» — фраза, которую крипта произносит уже 10 лет. WAGI-1 — робот, который ждёт. |

## 4. Токеномика

**Эмиссия:** 1,000,000,000 $WAGI, выпущены один раз, минт-функции не существует.

| Доля | Назначение | Условия |
|---|---|---|
| 40% | Инференс-награды | 5 лет, за полезные вычисления |
| 15% | Аирдроп | merkle-клейм, gasless (permit) |
| 15% | Ликвидность | 80/20 пулы, блокировка 2 года |
| 12% | Команда | клифф 6 мес, вестинг 24 мес (ончейн) |
| 10% | DAO-казна | гранты, аудит, листинги |
| 8% | Инвесторы | вестинг 18 мес |

**Дефляция:** 5% каждой комиссии сжигается. При 10 млн запросов/день и средней
комиссии 0.3 WAGI сеть сжигает ~150K WAGI/день. Использование растёт →
supply падает → цена услуги в фиате может падать, а в $WAGI — расти.

## 5. Архитектура

```
Агент/приложение ──HTTPS──► WenAGI Gateway (OpenAI-совместимый)
                               │ метрика токенов, биллинг $WAGI
                               ▼
                     InferenceMarket.sol (Base)
                     ├── 80% GPU-провайдеру
                     ├── 15% DAO-казне
                     └── 5% BURN ──► AGIProgressOracle.sol
                                      «wen AGI?» → 0..100%
```

Контракты (`contracts/src/`):
- **WagiToken.sol** — ERC-20, fixed supply, burn, EIP-2612 permit.
- **InferenceMarket.sol** — сеттелемент запросов, распределение комиссий; `settleBatch()` закрывает до 100 промптов одной транзакцией (атомарно).
- **AGIProgressOracle.sol** — 10 эпох прогресса, пороги по сожжённому объёму.
- **WagiAirdrop.sol** — merkle-аирдроп с защитой от двойного клейма.
- **TokenVesting.sol** — линейный вестинг с клиффом, revocable.
- **WagiMultisig.sol** — встроенный мультисиг-кошелёк (submit → подтверждения
  → execute; смена владельцев/порога только через self-call).

**Управление:** ни один EOA не держит привилегий — TreasuryMultisig 3/5 (DAO,
владелец всех контрактов), RelayerMultisig 2/3 (сеттелемент батчей),
OracleMultisig 2/3 (обновления прогресса).

Тесты: 44/44 зелёные, включая property-инварианты на случайных данных (`cd contracts && npm test`). Покрытие: сплиты комиссий,
replay-защита, permit-подписи, merkle-пути, вестинг-расписания, лимиты оракула,
полный цикл мультисиг-гovernance (кворум, ревок, self-call админ, «одиночный
ключ не может ничего»).

## 6. Дорожная карта

- **Phase 0 (готово):** контракты + тесты + демо-шлюз + плейграунд.
- **Phase 1 (T-14д):** виральная волна, квесты, 100K подписчиков.
- **Phase 2 (TGE):** аудит → деплой на Base → 80/20 пул → клейм аирдропа.
- **Phase 3 (T+30д):** mainnet-шлюз, реальные модели, ончейн-сеттлемент, SDK.
- **Phase 4 (T+90д):** рынок GPU — любой сдаёт видеокарту и зарабатывает.
- **Phase 5 (WEN):** AGI. Прогресс-бар дойдёт до конца. Мы обещаем ничего
  не обещать.

## 7. Риски и честность

- Смарт-контракты **не аудированы** — аудит запланирован до TGE (Phase 2).
- Релейер доверенный для метрики токенов, но не может тронуть средства сверх
  одобренной пользователем комиссии.
- Прогресс AGI — нарративный индикатор по реальному сжиганию, не научная
  метрика. Мы говорим об этом прямо, потому что честность — часть бренда.
- NFA. Это не инвестиционная рекомендация.
