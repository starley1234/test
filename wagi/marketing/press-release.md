# WenAGI запускает $WAGI — токен для LLM-инференса, который сжигается с каждым ИИ-запросом

*Децентрализованный рынок инференса с OpenAI-совместимым API переводит оплату
ИИ на рельсы блокчейна: 80% каждой комиссии получают GPU-провайдеры, 5%
сжигается навсегда*

**[Город, Дата]** — Команда WenAGI анонсирует запуск $WAGI — токена
стандарта ERC-20 в сети Base, выполняющего роль расчётной единицы
децентрализованного рынка LLM-инференса. Каждый запрос к OpenAI-совместимому
API сети оплачивается в $WAGI; смарт-контракт InferenceMarket распределяет
комиссию: 80% — GPU-провайдеру, обслужшему запрос, 15% — казне DAO,
5% сжигается безвозвратно.

Эмиссия ограничена 1 000 000 000 токенов, функция дополнительного выпуска
отсутствует на уровне кода. Таким образом, рост использования ИИ напрямую
уменьшает circulating supply — дефляционная механика, привязанная к реальному
спросу на вычисления, а не к расписанию эмиссии.

Ключевая особенность проекта — «прогресс-бар до AGI»: оракул
AGIProgressOracle публикует единый показатель 0–100%, рассчитываемый по
кумулятивному объёму сожжённых токенов. Показатель отвечает на вопрос,
который крипто-сообщество задаёт более десяти лет — «wen AGI?».

«ИИ-агенты не могут открыть банковский счёт, но прекрасно владеют
крипто-кошельками, — отмечают основатели WenAGI. — Машины должны платить
машинам — и у этой экономики должна быть своя единица расчёта».

Технические материалы: 5 смарт-контрактов (токен с поддержкой EIP-2612,
рынок инференса, merkle-аирдроп, вестинг, оракул прогресса) с открытым кодом
и автоматизированными тестами. Перед запуском основной сети контракты
проходят независимый аудит.

## Краткие факты (Q&A для редакций)

- **Что оплачивается $WAGI?** Запросы к LLM через OpenAI-совместимый API.
- **Почему дефляция?** 5% каждой комиссии сжигается контрактом. Использование
  растёт — supply падает.
- **Как получить?** Аирдроп за утилити-квесты (15% supply), затем DEX.
- **Какая сеть?** Base (EVM, L2).
- **Это мем-коин?** Это мем И утилити: мем двигает распространение, утилити
  удерживает экономику.
