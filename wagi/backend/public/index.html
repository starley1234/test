Утилити, а не просто мем

$WAGI — газ для машинного интеллекта: им оплачивают LLM-запросы, им же платят GPU-провайдерам. Экономика закрыта с двух сторон.

01

Плати за промпт токенами

OpenAI-совместимый endpoint: /v1/chat/completions. API-ключ, баланс в $WAGI — существующие агенты подключаются заменой одной строки.

02

80/15/5 — всё прозрачно

80% комиссии — GPU-провайдеру, 15% — DAO-казне, 5% сжигается ончейн. Ни одной скрытой комиссии.

10 эпох до AGI

Эпохи фиксируются смарт-контрактом по суммарному сожжённому $WAGI. Откат невозможен.

Аирдроп: 15% supply

Выполняй квесты — получай очки. Снапшот перед TGE, клейм без газа (permit). Каждое очко = аллокация.

Дорожная карта

PHASE 0 — DONEКонтракты + плейграунд

Смарт-контракты написаны и протестированы (44 теста), управление — 3 мультисиг-кошельками, демо-шлюз работает прямо на этой странице.

PHASE 1 — T-14 днейВиральная волна

Квесты, стена промптов, карточки прогресса. 100K подписчиков до TGE.

PHASE 2 — TGEДеплой на Base + DEX

Аудит, деплой, 80/20 пул, клейм аирдропа через permit.

PHASE 3 — T+30 днейГлавныйнет-шлюз

Реальные модели за $WAGI, ончейн-сеттлемент каждого запроса, SDK для агентов.

PHASE 4 — T+90 днейРынок GPU

Любой сдаёт свою видеокарту в сеть и зарабатывает $WAGI. Proof-of-useful-work.
