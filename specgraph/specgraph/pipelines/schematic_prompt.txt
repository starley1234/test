Ты инженер по аппаратуре. На изображении принципиальная или функциональная схема.
Найди блоки/узлы (микросхемы, преобразователи, интерфейсы, датчики, питание) и связи между ними.

Верни ТОЛЬКО JSON:
{
  "title": "краткое имя схемы",
  "nodes": [
    {"id": "короткий_id_латиницей_или_как_на_схеме", "name": "человекочитаемое имя", "kind": "psu|mcu|interface|sensor|logic|other"}
  ],
  "edges": [
    {"from": "id", "to": "id", "signal": "питание|шина|сигнал"}
  ]
}
Не выдумывай узлы, которых нет на рисунке. id должен быть узнаваем по надписи на схеме.
