# Как добавить пайплайн

Файл: `specgraph/pipelines/catalog.json`

```json
"my-check": {
  "slot": "expensive",
  "title": "Моя проверка",
  "system": "Ты инженер. Смотри только текущие требования. Скажи, чего не хватает для теста."
}
```

- `slot`: `cheap` (дёшево, кратко) или `expensive` (сложное решение)
- `system`: инструкция модели. Пишите по-русски, коротко.

Вызов:

```
POST /pipelines/my-check
{ "query": "...", "product_code": "MK-SSJ-NEW" }
```

Граф всегда один: **достать контекст из БД → спросить модель → вернуть текст**.

Код трогать не нужно, если хватает этого шаблона.

Если нужен свой шаг (например, только требования без изделий) — копируйте функцию в `pipelines/graphs.py` и вызовите `_compile`.

## Матрица корректности (методика А.3)

Файлы методики и образца: `input/for_pipeline1/`.

1. Загрузите спецификацию требований (`POST /documents` или пакет).
2. `POST /pipelines/review-correctness` `{ "document_id": N }`
3. Скачайте `download` — Word как `matrix.docx`: шапка, строки +/–/н/п, замечания.

Критерии правятся в `pipelines/correctness_checklist.json` (снято с таблицы А.3).
Оценка: дорогая модель; без ключа — простые правила (чтобы файл всё равно собрался).
