# SpecGraph — коротко для разработчика

## Что это

Сервис: **загрузили Word → в БД изделия и требования со связями → LLM читает граф**.

Не чанки текста. Два дерева:

- **Изделие** (система → модуль)
- **Требование** (карточка из Word)

Плюс рёбра: «требование относится к изделию», «сделано из вышестоящего», «файл-приложение».

## Ревизии

Код в Word: `ЧТО-УГОДНО.001/A.03`

- до `/` — **постоянный id** (`base_code`)
- после `/` — **ревизия** (`A.03`)

Пришла новая версия того же `base_code`:

1. старый текст кладётся в `requirement_revisions`
2. текущая строка обновляется
3. пайплайны видят **только текущую** (`is_current=true`)

История: `GET /requirements/{id}/revisions`

## Если в Word сменили подписи полей

Не лезьте в Python. Откройте `specgraph/profiles/default.json`:

- `card_must_have` — какие подписи в 1-й колонке таблицы значат «это карточка»
- `card_fields` — как подпись → поле (`содержание` → `text`)

Сохранили файл — перезапустили API.

## Три модели (.env)

| Слот | Зачем |
|---|---|
| `CHEAP_*` | короткое резюме |
| `EXPENSIVE_*` | проверка, тесты |
| `EMBED_*` | поиск. Пустой `EMBED_BASE_URL` = локальная модель |

У каждого: `BASE_URL`, `API_KEY`, `MODEL`.
