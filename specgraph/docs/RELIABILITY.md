# Как сделать надёжнее (по приоритету)

1. **Не грузить два пакета сразу в одну БД без транзакции на пакет.** Сейчас `ingest_many` идёт файл за файлом. Если второй файл упал — первый уже записан. Ок для ручной загрузки. Для автозагрузки: один `commit` в конце пакета.

2. **Сравнивать ревизии, а не только текст.** Уже так: другая `/A.03` → архив. Если внешняя система шлёт тот же `/A` но другой текст — тоже архив. Если шлёт тот же `/A` и тот же текст — ничего не пишем.

3. **Не удалять stub**, пока не пришёл настоящий текст. Иначе порвутся связи «источник требования».

4. **Хранить исходный Word** (`documents.storage_path`) — уже есть. Не чистить `data/uploads`.

5. **Позже:** уникальный индекс `(base_code) WHERE is_current` в Postgres — один «текущий» на код.

6. **Позже:** Alembic, если БД живая (сейчас таблицы создаются при старте).

7. **Позже:** эмбеддинги пересчитывать только у изменённых требований.

8. **Не парсить ID маской проекта.** Карточка = таблица с подписями. Это уже так.
